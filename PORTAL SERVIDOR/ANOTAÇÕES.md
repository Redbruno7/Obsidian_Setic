# MANUAL DE FÉRIAS

Perfis de acesso
	- O servidor realiza a marcação através do portal;
	- O chefe imediato, RH e titular da pasta realiza o gerenciamento das férias no SID;

Solicitação de férias
	- O servidor marca as férias pro ano posterior;
	- O servidor acessa o portal;
	- O servidor solicita na seção de Serviços -> Solicitar -> Pedir marcação anual de férias -> Solicitar Serviço;
	- As solicitação somente podem ser feitas dentre o período: 01/08 - 30/09;
	- Só poderá ser feita a solicitação para o servidor com mais de 1 ano de serviço;
	- O acompanhamento da solicitação pode ser verificado através da seção Serviços -> Acompanhar -> Férias.

Observações
	- Os prazos de marcação e de alterações são definidos pela SEGEP;
	- Em caso de problemas com a marcação ou perda de prazo, o servidor deve procurar o RH de sua unidade para orientação, para a correta marcação ou esclarecimento do motivo de instabilidade do serviço;
	- Em caso de problemas técnicos do sistema, como instabilidade, erro do sistema ou impedimento de manuseio, o servidor deve registar um chamado.
