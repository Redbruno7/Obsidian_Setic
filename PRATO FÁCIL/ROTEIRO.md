2. CONTA ADMINISTRATIVA

2.1. Processar Dados

![[processar_Dados.png]]

		Uma das principais funcionalidades administrativas é o processamento de dados, responsável pela atualização da base de beneficiários do programa.
		Nesse módulo, é realizada a importação de uma planilha previamente preparada e pré-auditada pela Caixa Econômica Federal.
		O processamento permite inserir e atualizar os benefiários, servindo também como base para os procedimentos de credenciamento e descredenciamento.
		É importante destacar que essa atualização possui uma referência mensal, sendo utilizada para reger a situação dos beneficiários no mês anterior ao processamento.
		Dessa forma, o sistema mantém a base de beneficiários atualizada para a continuidade da execução do programa.

___
2.2. Pedidos Retroativos

![[lista_Pedidos_Retroativos.png]]

		Outro recurso disponível para a administração é o gerenciamento de pedidos retroativos.
		Essa funcionalidade é utilizada principalmente em situações nas quais ocorrem falhas no sistema que impedem o registro normal dos pedidos realizados pelos estabelecimentos.
		Nesses casos, o estabelecimento encaminha para uma solicitação à SEAS, por meio do preenchimento de um formulário, informando os dados necessários para regularizar os pedidos.

![[solicitacao_Pedido_Retroativo.png]]

		Após receber e analisar a solicitação, a equipe responsável pode realizar a geração da autorização correspondente.
		É importante destacar que essas solicitações trabalham com informações quantitativas, como a quantidade de refeições que precisam ser regularizadas, e não com o registro individual de cada beneficiário.
		Assim, o módulo permite formalizar e controlar essas situações excepcionais.

___
2.3. Relatórios

![[relatorio_Estabelecimento.png]]

![[relatorio_Municipio.png]]

		O módulo de relatórios permite acompanhar os pedidos realizados dentro do programa, oferecendo diferentes possibilidades de consulta.
		As informações podem ser filtradas tanto por estabelecimento quanto por município, conforme a necessidade do usuário.
		Para realizar essas consultas, o sistema disponibiliza campos de seleção, nos quais o usuário define os parâmetros desejados.

![[relatorio_Estabelecimento_Completo.png]]

![[relatorio_Estabelecimento_Simples.png]]

![[relatorio_Municipio_Completo.png]]

![[relatorio_Municipio_Simples.png]]

		Além da escolha do estabelecimento ou município, é possível selecionar um período específico e as categorias disponíveis para consulta.
		Com esses filstros, o sistema apresenta um relatório consolidados dos pedidos realizados, permitindo acompanhar as movimentações dentro do intervalo selecionado.
		Depois de gerar o relatório, o usuário pode visualizar as informações consolidadas e também realizar a exportação dos dados para um planilha externa.
		Isso facilita a utilização dessas informações em controles administrativos, conferências e análises porteriores.

![[Pasted image 20261113132445.png]]

		Passando para o gerenciamento dos estabelecimentos, temos um módulo destinado ao acompanhamento dos restaurantes participantes do programa.
